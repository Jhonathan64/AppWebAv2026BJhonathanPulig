# 2026-11-01

## Song Screen Implementation (WebForms, ASP.NET Framework 2.0)

Implemented full Song functionality in WebAppPoliMusicV2 monolithic project:

### Files Created:
- **Entities/Song.cs** — Song entity with ID (int), Name (string), Path (string), Plays (int). Follows same pattern as Entities/User.cs.
- **DAL/Song.cs** — Data Access Layer using ADO.NET (SqlConnection, SqlCommand, SqlDataAdapter). Queries `[TBL_SONG]` with columns `ID_SONG, SONG_NAME, SONG_PATH, SONG_PLAYS`. Returns DataTable via `GetAll()` method.
- **BLL/Song.cs** — Business Logic Layer wrapping DAL.Song. Constructor takes connection string, `GetAll()` delegates to `DAL.Song.GetAll()`.
- **Song.aspx** — Responsive WebForms page with blue-themed Spotify-like design. Sticky header with welcome label + logout link. GridView with TemplateField containing HTML5 `<audio controls>` bound to `Eval("SONG_PATH")`. Blue gradient backgrounds (#0a1929, #0d47a1, #1565c0), celeste accents (#4fc3f7, #82b1ff). Mobile responsive at 768px breakpoint.
- **Song.aspx.cs** — Code-behind: reads `BDD_PoliMusicConnectionString` from Web.config, checks `Session[Util.Constants.USER]` (redirects to Login.aspx if null), displays welcome username, binds GridView via `BLL.Song.GetAll()`.
- **Song.aspx.designer.cs** — Designer file declaring `formSong`, `lblWelcome`, `lnkLogout`, `gvSongs` controls.

### Files Modified:
- **WebAppPoliMusicV2.csproj** — Registered all new files: `Song.aspx` (Content), `Entities/Song.cs`, `DAL/Song.cs`, `BLL/Song.cs`, `Song.aspx.cs`, `Song.aspx.designer.cs` (Compile).

### Conventions Followed:
- Connection string name: `BDD_PoliMusicConnectionString`
- Session key: `Util.Constants.USER`
- Namespace pattern: `WebAppPoliMusicV2.Entities`, `.DAL`, `.BLL`, `.Util`
- Constructor injection of connection string in DAL/BLL (matching User pattern)
